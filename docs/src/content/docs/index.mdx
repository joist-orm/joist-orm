  <section aria-label="N+1 prevention">
    <div class="feature-preview__copy">
      <span class="feature-preview__eyebrow">Performance</span>
      <h3>N+1 safe by default</h3>
      <p>Write natural async code. Joist batches relation loads across the loop into one query.
      No manual dataloader boilerplate. 🎉</p>
      <a href="/goals/avoiding-n-plus-1s/">Explore N+1 prevention →</a>
    </div>
    <div class="feature-preview__code">
      ```ts
      const books = await author.books.load();
      await Promise.all(books.map(async (book) => {
        // Any "load in a loop" issues 1 SELECT for all books' reviews
        const reviews = await book.reviews.load();
      }));
      ```
    </div>
  </section>
  <section aria-label="Reactive validation rules">
    <div class="feature-preview__copy">
      <span class="feature-preview__eyebrow">Business logic</span>
      <h3>Reactive rules</h3>
      <p>Declare business invariants _across entity-boundaries_ and Joist will rerun them whenever any data changes.</p>
      <p>No spaghetti code for "when this data changes, remember to re-check this other data."</p>
      <a href="/modeling/validation-rules/#reactive-validation-rules">Explore reactive rules →</a>
    </div>
    <div class="feature-preview__code">
      ```ts
      // Declared in `Author.ts`, enforced for all writes through `em.flush()`
      authorConfig.addRule(
        // Watch for changes to books' titles and author's first name
        { books: "title", firstName: {} },
        (a) => {
          const { books } = withLoaded(a);
          if (books.some((b) => b.title === a.firstName)) {
            return "A book cannot share its author's name";
          }
        },
      );
      ```
    </div>
  </section>
  <section aria-label="Reactive fields">
    <div class="feature-preview__copy">
      <span class="feature-preview__eyebrow">Business logic</span>
      <h3>Reactive fields</h3>
      <p>Write derived values that summarize cross-entity data and automatically stay up to date whenever their source data changes. No forgetting to manually recalc dirty fields.</p>
      <a href="/modeling/reactive-fields/">Explore reactive fields →</a>
    </div>
    <div class="feature-preview__code">
      ```ts
      class Author extends AuthorCodegen {
        readonly numberOfBooks: ReactiveField<Author, number> =
          hasReactiveField("books", (author) => {
            // Write arbitrary business logic
            return author.books.get.length;
          })
      }
      ```
    </div>
